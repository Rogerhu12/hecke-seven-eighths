二、复位：所用向量、归一化和实际 Weyl 作用
----------------------------------------
设 c>0，β∈C× 且 β=c。使用 Axiom 的实际 Theta β、imageAction、dPiComplexUpperRoot 和 whittakerValue。
定义归一化根算子
  E_+ = 2/(i c) · dπ(Z_plus),
  E_- = 2/(i c) · dπ(Z_minus)。
它们作用在 Whittaker 值上分别是乘 y 和 conjugate(y)。
从既有归一化球向量 vZero 开始，m≥0 时 φ_m=E_+^m vZero，m<0 时 φ_m=E_-^(-m) vZero。
这里负角权使用自然数阶的另一根串；并非对 E 求逆。

令 r=|y|_ord、ω=y/r。whittaker_archRootVector 的结论是
  Wβ(φ_m,y) = r^(|m|+1) ω^m K_(1/3)(c r)。
论文的复位归一化绝对值为 |y|_v=r²，故这恰是
  |y|_v^((|m|+1)/2) ω^m K_(1/3)(c |y|_v^(1/2))。

论文和 Axiom 使用同一个交换矩阵 w=[[0,1],[1,0]]。
实际 Weyl 证明不依赖“Whittaker 值相等所以向量相等”的未给定单射性：
  1. 直接计算最高谐函数在右乘 w 下成为其共轭；
  2. 提取上游局部最高谐函数的根导数计算，保留原有证明；
  3. 对实参数复值曲线应用 deriv.star，得到最低谐函数的另一根递推；
  4. 正负根串在最高/最低谐函数上的标量递推相同；
  5. 用 w²=1 与整数正负分类，得到 imageAction(w,φ_m)=φ_(-m)。
HighestHarmonicRoot 的局部计算源于上游 TensorProduct/HighestRoot.lean；没有导入该文件的全局实现链。
归一化及来源在源码头、许可证与 NOTICE 中公开。

RootIterates 的四条纯算子引理独立成立，但实际 Weyl 结论由上述具体计算证明；没有将抽象引理的未证假设当成具体模型的结论。

三、真实轮廓、Mellin 公式、常数和定义域
----------------------------------------
记
  a=(|m|+1)/2，A=4/c²，G(z)=Gamma(z−1/6) Gamma(z+1/6)。
在 t>0 上，两个字面 Bessel 轮廓为
  D(t)=t^(a−iτ) K_(1/3)(c√t)，
  H(t)=t^(a+iτ) K_(1/3)(c√t)。
代码先将它们写成 t 的复幂乘实际 thirdBesselRadialProfile，再证明与上述公式相等。
ComplexProfileBridge 从真实 φ_m、π(w)φ_m 的 Whittaker 值，移除相应角向因子并加入正负径向字符，证明这两个轮廓识别。

Mellin 约定为 M f(s)=∫_(0,∞) f(t) t^s dt/t。实际 Bochner 积分的结果为
  M D(s) = C_- A^s G(a+s−iτ)，
  M H(s) = C_+ A^s G(a+s+iτ)，
其中
  C_- = (1/2) A^(a−iτ)，C_+ = (1/2) A^(a+iτ)。
两个 HasMellin 定理分别要求 Re(s)>1/6−a；它们同时证明绝对可积性与积分值。

在 1/6−a < Re(s) < a−1/6 上，
  M H(s)=M D(−s) · A^(2s) · A^(2iτ) · G(a+s+iτ)/G(a−s−iτ)。
分母 Gamma 因子的实部为正，因此先证明非零再相除。
a≥1/2，所以所有整数角权均可使用共同开条带 −1/3<Re(s)<1/3。

固定相位 P=A^(2iτ) 的模为1，但一般不是1。
显式定义 H_normalized=P^(-1)H 后，另有不含 P 的反射恒等式。
这是明确的固定标量归一化；没有通过 Mellin 变换的期望答案定义 H。

当 c=4π 时，A=1/(4π²)。
独立局部乘积、角向 Haar 总质量取1、径向测度取 dt_v/t_v 时，常数为
  A0=∏_v A_v，
  C0=vol(U) · 2^(-r) · ∏_v A_v^(a_v−iτ_v)，
  C_ref=vol(U) · 2^(-r) · ∏_v A_v^(a_v+iτ_v)。
这给出所需的显式常数；本任务没有形式化全局层面 X_l 的测度分解或全局 Fubini 定理。
若每位用 dr_v/r_v，保留 t_v=r_v² 和 Mellin 配重 r_v^(2s)，每位会额外产生1/2，需相应更改常数。
原始球向量或角向 Haar 若另有标量归一化，也须相应乘入，不能宣称这些常数独立于测度选择。

上述是收敛条带内的实际积分恒等式；并未声称在整个复平面上 Bochner 积分都收敛。
超出该条带的亚纯延拓、轮廓平移和全局核的增长估计不属于本次已形式化结论。

四、与所给骨架的径向参数符号
----------------------------------------
给定 GlobalThetaData 定义 ρ=archRadial θ=−heckeComplexParameter θ。
旧 AngularThirdBesselMellin 的 actual_archGammaProduct_forward 已把真实正向轮廓 t^(a+iρ)K 的变换识别为
  Gρ(s)=Gamma(a+s+iρ−1/6) Gamma(a+s+iρ+1/6)。
因此对应反射 Gamma 商应为
  G_(-ρ)(s)/Gρ(−s)，

  Gρ(s)/G_(-ρ)(−s)。

五、有限位：精确有限和与数字表
----------------------------------------
令 k 为 q 元有限域，χ:k→C 为零延拓的六阶乘性特征，ψ 为本原加性特征。
取 t∈k×、j∈{0,1,2,3,4,5}、e∈N。
写 Gψ(η)=Σ_(x∈k) η(x)ψ(x)，τ_j=Gψ(χ^(-j))，γ2=q^(-1/2)Gψ(χ²)。
零延拓的平凡乘性特征在0处为0，因而 j=0 必须与常数函数区分。

球系数为
  W_(3k)=q^(-k)，W_(3k+1)=q^(-k−1/2)γ2，W_(3k+2)=0。
有限 Weyl 表达式为
  Rβ(e,t)=W_e χ(t)^(4+2e) Σ_(v≠0) β(v)χ(v)^4 Ψ_e(t/v)，
其中 Ψ_0=ψ，而 e>0 时 Ψ_e=1。
证明使用实际换元 x=t/v：
  Σ_v η(v)ψ(t/v)=η(t)Gψ(η^(-1))，
然后使用乘性特征正交性。

标记权重 β(v)=q^(-1) 的 active 部分：
  e=0: q^(-1/2)γ2 χ(t)²；
  e>0: 0。
其 inactive 权重为 q^(-1)，完整 inactive 贡献还要乘原球 Whittaker 值。

普通表 active 部分：
  e=0,j=0: −q^(-1/2)γ2 χ(t)²；
  e=0,j≠0: Gψ(χ^(j−4))/τ_j · χ(t)^(8−j)；
  e>0: 1_(j=4) (q−1)/τ_4 · W_e χ(t)^(4+2e)。
j=0 的 inactive 权重是1−q^(-1)。
字符指数可模6约化；代码使用 (j+2)%6 表示 j−4 模6。
localWeylExponent 是 e=0 时 (8−j)%6，否则 (4+2e)%6。
证明从有限和中分离任意单位 t 的相位，不把该相位关系作为新假设。

范数和非零性：1≤j≤5 时 |τ_j|=√q、τ_j≠0；|γ2|=1。
注意 τ0=−1，不能将 |τ_j|=√q 的结论扩张到 j=0。
零深度所有标量模≤1，j=1 的行素位标量模恰为1。
正深度有 |s_(j,e)|≤√q |W_e|，故
  |s_(j,3k+1)|≤q^(-k)，
  |s_(j,3(k+1))|≤√q q^(-(k+1))，

“正深度只有j=4”及上述支撑消失均只指 active/nonzero-digit 部分，不能泛化到含 inactive 项的整个平均。

01. rootIterate  [def]
定义 E^n(v)：零次为 v，后继次为 E(E^n(v))。
Lean声明：
def rootIterate {V : Type u} (E : V → V) : Nat → V → V

02. intertwining_rootIterate  [theorem]
若 W∘E=F∘W，则 W(E^n v)=F^n(Wv)。
Lean声明：
theorem intertwining_rootIterate {V : Type u} (W E F : V → V)
    (h : ∀ v, W (E v) = F (W v)) (n : Nat) (v : V) :
    W (rootIterate E n v) = rootIterate F n (W v)

03. commuting_rootIterate  [theorem]
若 F 与 Ebar 对易，则 F(Ebar^n v)=Ebar^n(Fv)。
Lean声明：
theorem commuting_rootIterate {V : Type u} (F Ebar : V → V)
    (h : ∀ v, F (Ebar v) = Ebar (F v)) (n : Nat) (v : V) :
    F (rootIterate Ebar n v) = rootIterate Ebar n (F v)

04. opposite_rootIterate  [theorem]
若 F 与 Ebar 对易且 Fv0=Ebar v0，则 F^n v0=Ebar^n v0。
Lean声明：
theorem opposite_rootIterate {V : Type u} (F Ebar : V → V) (v₀ : V)
    (hcomm : ∀ v, F (Ebar v) = Ebar (F v))
    (hcompact : F v₀ = Ebar v₀) (n : Nat) :
    rootIterate F n v₀ = rootIterate Ebar n v₀

05. weyl_rootIterate  [theorem]
由 WE=FW、Wv0=v0、[F,Ebar]=0、Fv0=Ebar v0，推出 W(E^n v0)=Ebar^n v0；本通用引理不代替实际模型的验证。
Lean声明：
theorem weyl_rootIterate {V : Type u} (W E F Ebar : V → V) (v₀ : V)
    (hweyl : ∀ v, W (E v) = F (W v))
    (hspherical : W v₀ = v₀)
    (hcomm : ∀ v, F (Ebar v) = Ebar (F v))
    (hcompact : F v₀ = Ebar v₀) (n : Nat) :
    W (rootIterate E n v₀) = rootIterate Ebar n v₀

2. def digitTau
普通数字的 Gauss 分母 τ_j=G(χ^(−j))，对全有限域求和。
def digitTau (χ : MulChar F ℂ) (ψ : AddChar F ℂ) (j : ℕ) : ℂ :=

3. def ordinaryDigit
j=0 时为 δ_0−q⁻¹；j≠0 时为 τ_j⁻¹χ^(−j)，采用乘性特征的零延拓。
def ordinaryDigit (χ : MulChar F ℂ) (ψ : AddChar F ℂ) (j : ℕ) (v : F) : ℂ :=
  if j = 0 then
    if v = 0 then 1 - (Fintype.card F : ℂ)⁻¹ else -(Fintype.card F : ℂ)⁻¹
  else (digitTau χ ψ j)⁻¹ * (χ⁻¹ ^ j) v

4. def finiteWeylSum
W_eχ(t)^(4+2e)Σ_v β(v)χ(v)^4 Ψ_e(t/v)，其中 Ψ_0=ψ，正赋值 Ψ_e=1。
def finiteWeylSum (χ : MulChar F ℂ) (ψ : AddChar F ℂ)
    (W : ℕ → ℂ) (β : F → ℂ) (e : ℕ) (t : Fˣ) : ℂ :=
  W e * χ t ^ (4 + 2 * e) *
    ∑ v : F, β v * (χ ^ 4) v * (if e = 0 then ψ ((t : F) / v) else 1)
